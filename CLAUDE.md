# Orientações para agentes

As instruções deste projeto são mantidas em um arquivo só, `AGENTS.md`, para que Claude Code, Codex e qualquer outra ferramenta sigam exatamente as mesmas regras. Leia `AGENTS.md` antes de alterar qualquer coisa.

Duas cópias das mesmas regras divergem com o tempo. Se precisar mudar uma regra, mude em `AGENTS.md` e não recrie o conteúdo aqui.
